# Portafolio — Isaías

Abre `index.html` en el navegador (no requiere instalación).

```
portafolio/
├── index.html          Estructura y contenido (textos, proyectos, contacto)
├── css/
│   ├── base.css        Colores, modo oscuro, reset y tipografía
│   ├── nav.css         Barra de navegación
│   ├── hero.css        Portada, botones y figuras
│   ├── sections.css    Sobre mí, proyectos, talentos, pasatiempos, contacto
│   ├── animations.css  Animaciones y efectos hover
│   ├── decorations.css Figuras matemáticas (SVG) de fondo
│   ├── layout.css      Secciones a pantalla completa
│   └── responsive.css  Accesibilidad y adaptación a celular/tablet
└── js/
    └── main.js         Barra de progreso y aparición al hacer scroll
```

Los CSS se cargan en el orden de `index.html`; ese orden importa.
